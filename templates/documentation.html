    ArUCO Generator Documentation

    Getting Started

    Welcome to the ArUCO Generator documentation. This professional-grade tool provides everything you need for generating, calibrating, and validating computer vision markers used in robotics, augmented reality, and computer vision applications.

    Quick Start Guide

    1. Generate Markers: Start with the Generate page to create ArUCO markers
      • Quick Generate: Single markers or small grids
      • Advanced: Complex configurations with custom parameters
      • Batch: Generate multiple marker sets efficiently
    2. Create Calibration Patterns: Use the Calibration page for camera calibration
      • ChArUco boards for precise calibration
      • AprilTags for robotics applications
    3. Validate Detection: Test marker quality and detection reliability
    4. Export Results: Download in various formats (SVG, PDF, LightBurn, DXF)
    Tip: For most applications, the 6X6_250 dictionary provides the best balance of robustness and detection speed. Start with 50mm markers for standard indoor use.

    ArUCO Markers

    ArUCO markers are square fiducial markers used in computer vision applications for pose estimation, camera calibration, and augmented reality.

    Dictionary Selection

    Dictionary Bit Size Max Markers Use Case
    4X4_50 4x4 50 Fast detection, limited IDs
    5X5_100 5x5 100 Balanced performance
    6X6_250 6x6 250 Recommended for most uses
    7X7_1000 7x7 1000 Maximum robustness

    Size Recommendations

    • 20-50mm: Close-range detection (< 1m)
    • 50-100mm: Standard applications (1-5m)
    • 100-200mm: Long-range detection (5-10m)
    • >200mm: Outdoor/industrial use (>10m)

    Calibration Patterns

    ChArUco Boards

    ChArUco boards combine checkerboard patterns with ArUco markers for precise camera calibration.

    // Recommended ChArUco parameters
    Squares: 8x6
    Square Size: 30mm
    Marker Size: 22.5mm (75% of square size)
    Dictionary: 4X4_50

    AprilTags

    AprilTags are an alternative fiducial system preferred in robotics applications.

    • Tag36h11: Recommended - best error correction
    • Tag25h9: Faster detection, less robust
    • Tag16h5: Minimal computation, limited IDs

    Export Formats

    • SVG: Vector graphics for digital use and printing
    • PDF: Print-ready documents with precise dimensions
    • LightBurn (.lbrn2): Direct laser cutting with material presets
    • DXF: CAD/CNC machining compatibility
    • PNG: Raster images for web and applications
    LightBurn Export: Includes optimized cutting parameters for common materials (paper, cardboard, acrylic).

    Best Practices

    Printing Guidelines

    • Use matte paper to reduce reflections
    • Ensure high contrast (pure black on white)
    • Keep markers flat and undistorted
    • Add white borders (at least 1 bit width)

    Detection Optimization

    • Marker size should be ~1/5 of detection distance
    • Ensure even lighting without shadows
    • Camera resolution: at least 10 pixels per marker bit
    • Avoid motion blur with adequate shutter speed

    Common Pitfalls to Avoid

    Watch out for these issues:
    • Glossy paper: Creates reflections that confuse detection
    • Small borders: Always maintain at least 1 bit width of white border
    • Resolution mismatch: Ensure camera has 10+ pixels per marker bit
    • Poor lighting: Uneven lighting creates shadows and reduces accuracy
    • Warped markers: Keep printed markers perfectly flat
    • Wrong dictionary: Always verify you're using the correct dictionary in detection

    Troubleshooting

    Markers Not Detected

    • Check marker size relative to camera distance
    • Verify correct dictionary is being used
    • Ensure adequate lighting
    • Check for motion blur or focus issues

    Poor Pose Estimation

    • Calibrate camera for accurate intrinsic parameters
    • Use larger markers for better accuracy
    • Ensure markers are perfectly flat
    • Check for lens distortion

    High Confusion Rate

    • Use markers with larger Hamming distance
    • Switch to dictionary with more bits
    • Improve image quality and resolution
    • Add error checking in detection code
