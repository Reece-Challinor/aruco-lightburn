Usage Guidelines

Dictionary Selection:

  • 4×4: Fast detection, limited IDs
  • 5×5: Balanced performance
  • 6×6: Recommended for most uses
  • 7×7: Maximum robustness

Size Recommendations:

  • 20-50mm: Close-range detection
  • 50-100mm: Standard applications
  • 100-200mm: Long-range detection
  • >200mm: Outdoor/industrial use
Tip: Marker size should be ~1/5 of detection distance for optimal results
